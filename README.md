# fuchsblau for Chrome

Dark Chrome theme with vivid cyan accents on a deep blue-black background.

## Palette

| Element | Color |
|---------|-------|
| Frame | `#0D1117` |
| Toolbar | `#1C2128` |
| Text | `#B8C4D4` |
| Accent | `#00B9E8` |

## Install

1. Clone this repo
2. Open `chrome://extensions/`
3. Enable **Developer mode**
4. Click **Load unpacked** and select the repo directory
