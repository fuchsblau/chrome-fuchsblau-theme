# fuchsblau for Chrome

Dark-only Chrome theme on the fuchsblau stage. The browser chrome sits on
the same deep blue surfaces as the rest of the
[omarchy fuchsblau theme](https://github.com/fuchsblau/omarchy-fuchsblau-theme)
(Charter v0.2). No counted accent is spent here: icons and text stay quiet,
teal only appears where Chrome derives it itself.

## Palette

| Element | Token | Color |
|---------|-------|-------|
| Frame, inactive tabs, new tab page | `background` | `#1A2234` |
| Toolbar, active tab, omnibox | `lighter_background` | `#232C44` |
| Text | `foreground` | `#CDD6EE` |
| Toolbar icons, inactive tab text | `light_foreground` | `#A8B1D2` |
| Tab text in inactive windows | `muted` | `#4E5784` |
| Links (new tab page) | `blue` | `#88AEDE` |
| Incognito frame | `darker_background` | `#0D111A` |

## Install

1. Clone this repo
2. Open `chrome://extensions/`
3. Enable **Developer mode**
4. Click **Load unpacked** and select the repo directory
